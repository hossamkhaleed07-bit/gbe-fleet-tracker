# تغيير في طريقة إدخال الفواتير (من أول نوفمبر 2026)

الفواتير بقت مربوطة بالمحفظة. كل فاتورة بتتخصم من رصيد الحساب بتاعها أول ما تتحفظ.

**إيه اللي اتغيّر:**

1. **مفيش حذف للفاتورة بعد ما تتخصم.** زرار الحذف هيرفض مع أي فاتورة اتخصمت.
2. **لو الفاتورة غلط أو مش مقبولة:** اختار الفاتورة واضغط **إلغاء** أو **رفض**، واكتب السبب (إجباري).
   - الفلوس بترجع للحساب تلقائيًا.
   - الفاتورة الأصلية بتفضل موجودة ومعلّم عليها إنها اتلغت.
   - بيتسجل مين ألغاها، وإمتى، وليه.
3. **مفيش تعديل للمبلغ بعد الخصم:** Cost وAmount وVAT، والحساب (Card Type وBranch)، والتاريخ.
   - **التصحيح = إلغاء الفاتورة الغلط بسبب واضح، وبعدين إدخالها من جديد صح.**
4. **حاجات تقدر تعدّلها عادي:** الـ Remarks ولون الصف.
5. **الفاتورة الواحدة تتلغي مرة واحدة بس.**
6. **فواتير سبتمبر وأكتوبر مش داخلة في المحفظة،** وبتتعامل زي الأول.

**ليه؟** عشان كل ريال يبقى ليه أثر واضح، ورصيد كل حساب يطلع صح، وما يحصلش إن مصروف يتحسب مرتين أو يختفي.

**الإلغاء والرفض والقفل** بيعملهم الـ main admin بس. أي حد عنده صلاحية الإدخال يقدر يدخّل الفواتير زي الأول.
